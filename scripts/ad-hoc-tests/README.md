# Ad Hoc Test Scripts

This folder contains the repo's loose manual verification scripts that used to live at the repository root.

Examples:

- `bash scripts/ad-hoc-tests/test_admin_orders.sh`
- `python3 scripts/ad-hoc-tests/test_frontend_url_fix.py`
- `bash scripts/ad-hoc-tests/verify_order_detail.sh`

These are separate from the automated backend test suite in `shopsoma-backend/tests/`.
